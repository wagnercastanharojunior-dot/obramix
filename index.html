Conectar Google Drive
Sem senha, sem configuracao complexa.
Funciona com Google Sheets. Siga os 4 passos:
1
Acesse sheets.new — cria uma planilha nova no seu Google Drive
2
No menu da planilha: Extensoes → Apps Script
3
Apague tudo, cole o codigo abaixo e salve (Ctrl+S):
function doPost(e){ var ss=SpreadsheetApp.getActiveSpreadsheet(); var s=ss.getSheetByName("bkp")||ss.insertSheet("bkp"); s.clearContents(); s.getRange(1,1).setValue(e.postData.contents); s.getRange(1,2).setValue(new Date().toString()); return ContentService.createTextOutput( JSON.stringify({ok:true})) .setMimeType(ContentService.MimeType.JSON); } function doGet(e){ var s=SpreadsheetApp.getActiveSpreadsheet() .getSheetByName("bkp"); if(!s)return ContentService .createTextOutput("{}") .setMimeType(ContentService.MimeType.JSON); return ContentService.createTextOutput( s.getRange(1,1).getValue()) .setMimeType(ContentService.MimeType.JSON); }
4
Implantar → Nova implantacao → Tipo: App da Web → Quem pode acessar: Qualquer pessoa → Implantar → copie a URL e cole abaixo
Dados salvos na sua planilha do Google Drive. So voce tem acesso.
